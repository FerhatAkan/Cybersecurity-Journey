Week 2: Learning About Computers and the Web

1. Different Types of Computers

Today I learned about different types of computers, such as laptops, desktops, servers and workstations. I learned what they are used for and how they are different from each other.

I also learned that smartphones and tablets are computers too. Other examples are IoT devices, such as smart doorbells and thermostats, and embedded computers, which are built into things like coffee makers and automatic doors.

2. Computer Parts and Hardware

I learned about the different parts inside a computer, what they do and why they are important. I also learned the basics of building a PC and how the different parts work together.

3. Understanding HTTP and HTTPS

I learned what HTTP and HTTPS mean and how they are used when visiting websites.

At first, I had a hard time understanding what a stateless protocol meant, so I asked ChatGPT to explain it in simpler terms. I learned that it means each request is handled separately, without automatically remembering previous requests.

I also learned that HTTPS makes the connection between my browser and a website more secure by encrypting the information being sent.

4. How Websites Work

I learned about different HTTP methods, such as GET, POST, PUT and DELETE. These are used when my browser communicates with a website.

For example, when I visit Facebook, my browser sends a GET request to ask for information from the website. The server then sends back the information needed to display the page.

I also learned about the different parts of a website address. The scheme tells the browser which protocol to use, while the host identifies the website.

For example, in `https://www.facebook.com`, `https` is the scheme and `www.facebook.com` is the host.

Overall, I now have a better understanding of how computers work and what happens behind the scenes when I visit a website.
