# Week 3

**What I completed:**

• Learned about virtual machines, servers and databases.
• Learned about hypervisors and the two different types.
• Learned about Docker and containers.
• Learned about cloud computing and cloud servers.
• Learned about Public, Private and Hybrid clouds.
• Learned about IaaS, PaaS and SaaS.

**What I learned:**

• Virtual machines allow one physical computer to run multiple virtual computers.
• Servers provide services and information, while databases store and organize information.
• Hypervisors make it possible to run virtual machines.
• Docker is used to run applications inside containers.
• Cloud computing allows people and companies to use computing resources over the internet.
• Public, Private and Hybrid clouds offer different ways to use cloud services.
• IaaS, PaaS and SaaS are three different types of cloud services.

**What I found difficult:**

• There were many new technical terms to understand.
